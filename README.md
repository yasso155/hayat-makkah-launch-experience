# Hayat Makkah — VIP Guest Experience

A cinematic, high-end presentation system and operational protocol for the "Heritage of Two Lands" project. Designed for **Emlak Konut** and **NHC**, this application serves as a dedicated VIP pitch deck for luxury real estate and cultural hospitality in the Holy City.

## 🚀 Features

- **Cinematic Presentation Layer**: Full-screen, image-led slides with Ken Burns animations and elegant typography.
- **Bilingual Interface**: Seamlessly toggle between English and Arabic (RTL support).
- **VIP Operational Protocol**: Comprehensive slides covering Airport Arrival, VIP Transfer, Smart Integration, and Micro Luxury touchpoints.
- **PDF Export**: Optimized print engine that exports the entire 17-slide deck into a professional landscape PDF.
- **Smart Experience**: Integrated QR ecosystems and proactive guest hosting concepts.

## 🛠️ Technology Stack

- **React 19** + **TypeScript**
- **Vite** (Build Tool)
- **Framer Motion** (Cinematic Animations)
- **Tailwind CSS** (Premium Styling)
- **Lucide React** (Iconography)

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run locally**:
   ```bash
   npm run dev
   ```
